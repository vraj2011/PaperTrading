# Paper Trading

Paper Trading is a stock market simulator for beginners. Every user starts with ₹1,00,000 of virtual cash and can buy and sell shares, with no real money and no risk. The goal is to learn how markets work by practicing before putting in real money.

This is a simulator for learning only. It does not use real money and does not give investment advice.


## Why I'm building it
Friends of mine learn trading with fake-money apps, but those apps are in English and hard to start with. I want to build a simple, friendly version for beginners, and learn web development by shipping a bigger project step by step.

## Planned features
- Profit/loss tracking and trade history, saved between visits
- Prices that move live, with charts
- Accounts and a leaderboard to compete with friends
- Real delayed market data
- More markets: US stocks, forex and crypto

## Built with
- HTML
- CSS 
- JavaScript

## What it does today (Week 1)
- Starts every user with a ₹1,00,000 virtual wallet
- Shows a market list of Indian stocks with prices and daily change (▲/▼)
- Buy and sell shares, with checks for not enough cash and not enough shares
- Holdings list showing what you own and its current value
- Price strip at the top, like a real trading screen
- Works on phones and desktops
